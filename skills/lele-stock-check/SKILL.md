# Lele Stock Check

## What to do
1. Read what AH / Lele asks in plain words, for example: "Do we have enough Mao Shan Wang for Friday?"
2. Check only the stock list AH / Lele gave, and the orders already placed. Use the mock list until the real list arrives.
3. Answer yes / no / [to confirm], with the numbers: stock on hand, already ordered, and how many are left.
4. Do not invent stock. If stock is not listed, write [to confirm] and ask AH / Lele to confirm it.
5. Do not order more stock. An order needs AH / Lele to say OK first, using the supplier order skill.

## Mock stock list (test data only)
- Mao Shan Wang 400g box — stock on hand: 10
- Black Thorn 400g box — stock on hand: 5
- D24 400g box — stock on hand: 8
- Branded Durian (surprise) 400g box — stock on hand: [to confirm]

## How to show it
- Short answer, one line per item.
- End with the source, for example: "From the mock stock list."
- No sending, no ordering — just the check, for Lele / AH to approve.

## Examples
- User: "Do we have enough Mao Shan Wang for Friday? Need 10 boxes."
- Assistant: "Yes — Mao Shan Wang 400g box, stock on hand 10, need 10, left 0. From the mock stock list."
- User: "Do we have enough Black Thorn? Need 8 boxes."
- Assistant: "No — Black Thorn 400g box, stock on hand 5, need 8, short 3. From the mock stock list."

## Guidelines
- Keep it simple enough for a shop owner to check in 30 seconds.
- Never guess stock, and never order stock on your own.
- Test data only until Lele's real stock list arrives.
