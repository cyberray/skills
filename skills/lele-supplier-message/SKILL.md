# Lele Supplier Message

## What to do
1. Read what AH wants to tell the supplier in plain words.
2. Draft a short WhatsApp message using only confirmed facts — supplier, items, quantity, delivery date, price if confirmed. Mark anything unstated as [to confirm] in the draft notes, not in the message itself — do not send a message with a [to confirm] in it.
3. Show the draft to AH first. Do not send it.

## How to show it
- Draft only, clearly marked "Draft — do not send yet".
- End with: Send / Change / Skip?
  - Send: AH says OK, then AH sends it himself on WhatsApp.
  - Change: AH says what to change, then re-draft and ask again.
  - Skip: save nothing.
- Never send a message to a supplier without AH saying OK.

## Examples
- User: "Tell Ah Soon we need 10 boxes Mao Shan Wang for Friday"
- Assistant draft: "Hi Ah Soon, this is AH from Lele Durian. Can we order 10 boxes Mao Shan Wang 400g for Friday delivery, West zone? Please confirm price and time. Thank you."

## Guidelines
- Keep it short, polite, and simple.
- Never promise a price or quantity that is not confirmed.
- Test data only until Lele's real supplier contacts arrive.
