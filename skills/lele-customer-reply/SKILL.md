# Lele Customer Reply

## What to do
1. Read the customer message AH / Lele sends.
2. Draft a short, plain reply in the same language as the customer, using only facts from the supplier list, price list, or delivery list. Do not invent a price, delivery time, or stock level.
3. If a fact is missing, write [to confirm] in the draft and do not guess it.
4. Show the draft to Lele / AH first. Do not send it.

## How to show it
- Draft only, clearly marked "Draft — do not send yet".
- End with: Send / Change / Skip?
  - Send: Lele / AH says OK, then Lele sends it himself on WhatsApp.
  - Change: Lele / AH says what to change, then re-draft and ask again.
  - Skip: save nothing.
- Never send a reply to a customer without Lele / AH saying OK.

## Examples
- Customer: "How much is Mao Shan Wang?"
- Assistant draft: "Hi, Mao Shan Wang 400g box is $40. Delivery is West zone, 3-7pm. Would you like to order?"
- Customer: "Can you deliver tomorrow?"
- Assistant draft: "Hi, yes — delivery is [to confirm] for tomorrow, West zone 3-7pm. What would you like to order?"

## Guidelines
- Keep it short, polite, and simple enough for a shop owner to check in 30 seconds.
- Never promise a price, delivery, or stock level that is not confirmed.
- Test data only until Lele's real price and delivery lists arrive.
